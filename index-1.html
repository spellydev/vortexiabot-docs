Quick Start

Get Vortexia running in minutes

Follow these steps in order. You do not need every system configured before using the bot.

Add the bot

Use the official invite and choose your server. Grant the permissions needed for the systems you plan to use. Add Vortexia →

Check the connection

In your server run /ping. A healthy response confirms Vortexia can reach the guild.

Explore commands

Open the command center or use /help inside Discord to see available slash commands.

Configure systems

Set up leveling, welcome, tickets, automod or invite tracking when you are ready. Each system has its own setup commands.

Music

Advanced music workflow

Vortexia’s music system is built around a control panel rather than dozens of separate commands.

1. Open

Run /music to open the player panel.

2. Search & select

Search for a track and pick the result you want to play.

3. Control

Use playback, queue, volume, shuffle, loop and filter controls from the panel.

4. Persistent playback

Enable 24/7 or autoplay when you want continuous music.

Permissions

Use powerful commands safely

Discord permissions still matter even when a command is visible. Restrict high-impact actions to trusted staff.

🛡 Moderation

Ban, kick, timeout, mute, purge, lock and role actions should be limited to trusted moderators.

🔒 Security

Automod, command logs and server-wide safety tools should be configured by administrators only.

⚠ High-impact

Commands that affect many members (roleall, nuke, dmall) require careful permission and channel placement.

✓ Utilities

Most utility and fun commands are safe for everyone. Still review your server’s integration permission overrides.
