Add Vortexia to your Discord server

Vortexia is a free all-in-one Discord bot. Inviting it takes under a minute.

Add Bot to Server

Setup in 5 steps

  1. Click Add Bot and choose your server (you need the Manage Server permission).
  2. Authorize Vortexia and complete the captcha.
  3. Type /help to open the command center.
  4. Join a voice channel and run /music for the player panel.
  5. Run /ticket setup and the AutoMod panel to finish your server.

Permissions

The invite asks for Administrator so every module works out of the box. You can lower permissions in Server Settings → Roles, but music, moderation and tickets need channel and member management.

Having trouble?

Make sure Vortexia's role sits above the roles it should moderate. Still stuck? Join the support server. See also the FAQ and full command list.
