Privacy Policy

Last updated: October 2026.

Data the bot stores

Vortexia stores only what its features need: server and channel IDs, user IDs, settings, warnings, economy and level data, and ticket records. It does not read private messages.

This website

The website stores optional review and login data in your browser. Discord login only receives your public profile name and avatar.

Sharing

Data is not sold. It is only shared with infrastructure providers needed to run the bot.

Deletion

To request deletion of your data, join the support server and open a ticket. Removing the bot from your server stops further collection.
