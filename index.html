DISCORD

Permissions & Safety

Discord permissions and role hierarchy always control what Vortexia can do.

Moderation permissions

Ban, kick, timeout, message management, channel management and role management require the corresponding Discord permissions.

Bot role position

Place the Vortexia bot role above roles it needs to manage. Discord role hierarchy can block otherwise valid actions.

Administrator features

Some setup and server-wide systems may require administrator access or specific management permissions.

Keep secrets private

Never publish bot tokens, API keys, SMTP credentials or private configuration files in the docs repository.

DEVELOPERS

Self-hosting

For owners running their own Vortexia instance. The documentation build references Node.js 25.9.0 and discord.js 14.x.

Basic setup
1. Install Node.js 25.9.0
2. Keep your bot token and API keys private
3. Configure your bot's environment/configuration
4. Install dependencies: npm install
5. Start the bot using your project's start command
Security: GitHub Pages is for the public documentation website. Never upload config.json, bot tokens, database credentials or other secrets.
