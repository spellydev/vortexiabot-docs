Getting started

Learn the two ways to run Vortexia commands.

⌘

Slash commands

Type / in a Discord message box, select a Vortexia command, fill in the options Discord shows, then press Enter.

?

Prefix commands

Type a command beginning with ? in a server text channel, followed by its arguments. Example: ?weather Dhaka.

🎮

V-game commands

Game commands use the v prefix, for example v hunt or v profile.

Before you start: Vortexia must be in your server and have permission to view the channel and send messages. Setup and moderation commands may require Administrator, Manage Server, Manage Messages, Manage Roles, or another matching Discord permission. The bot's role must be above the roles it needs to manage.

Help & support

Use these tips when something does not work.

📖

In Discord

Run /help for the slash command help panel or ?help for the prefix command catalogue.

🛡️

Permission issue

Check your own Discord permissions, Vortexia's permissions, and the bot role position in Server Settings → Roles.

🔧

Command not showing

Confirm Vortexia was invited with the applications.commands scope. Newly updated slash commands may take time to appear in Discord.
