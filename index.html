FAQ

Quick answers.

Common questions before adding Vortexia.

How do I add Vortexia?

Use the Invite Bot button anywhere on this website, choose your server, review the permissions and authorize it.

Where can I see all commands?

Open Commands from the navigation. The command center is searchable and filterable, and every command can open a detailed usage view.

Can I configure only some systems?

Yes. Start with the systems you need. The Quick Start section is intentionally incremental.

Are website reviews shared with everyone?

Not in this standalone HTML build. They are stored locally in the visitor's browser. To make them global, connect the provided review API hook to your own backend or database.

Does the website connect to Vortexia?

Yes. When served by the bot, the page reads live bot status and commands from the Vortexia API. Discord OAuth2 powers the owner dashboard.

Does this website replace Discord?

No. It is a discovery and documentation layer for Vortexia. The actual bot features run inside Discord.
