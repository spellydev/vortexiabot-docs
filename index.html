Getting started

Three ways to run commands — pick what feels natural.

⌘

Slash commands

Type / in any channel, choose a Vortexia command, fill the options Discord shows, then hit Enter.

?

Prefix commands

Start with ? then the command name and args.
Example: ?weather Dhaka

🎮

V-game commands

Game & economy actions use the v prefix.
Examples: v hunt · v profile

Before you start: Invite Vortexia with the right permissions. The bot needs View Channel + Send Messages. Admin features (logs, reaction roles, verification…) also require Manage Server, Manage Roles, or Manage Messages. Keep the bot role above any roles it needs to assign or manage.

Help & support

Quick fixes for the most common issues.

📖

In Discord

Run /help for the interactive slash menu or ?help for the full prefix catalogue.

🛡️

Permission issues

Check your permissions, the bot’s permissions, and role hierarchy under Server Settings → Roles.

🔧

Command not showing

Make sure the invite included the applications.commands scope. New slash commands can take a few minutes to appear.
